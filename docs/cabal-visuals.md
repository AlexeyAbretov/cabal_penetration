# Cabal — картинки уровней, боссов и врагов

Референс для перерисовки. Картинки лежат на чужих сайтах и показываются по ссылке. В билд игры их не класть: рисунок аркады принадлежит TAD, рисунок Dendy — Rare.

Два слоя:

- **Чистые фоны** сняты с тайлов, дома ещё целые. Для Dendy это карты NES, для автомата — карты аркады.
- **Кадры сцен и боссов** с [Arcade Quarter Master](https://www.arcadequartermaster.com/cabal_bosses.html). Это аркада уже в бою: на кадре могут быть солдаты и первые дыры. Подпись уровня совпадает с разбором в `cabal-original.md`.

Отдельного листа «все враги Dendy на прозрачном фоне» в открытом доступе нет. Где смотреть врагов — в конце.

## Враги

Готового прозрачного листа врагов порта Rare нет. На Spriters Resource для NES выложен только солдат игрока: [Cabal NES](https://www.spriters-resource.com/nes/cabal/).

Листы врагов и боссов есть у порта на Amstrad CPC. Это другой рисунок и мало цветов, для облика Dendy не подходят:

- [Enemies](https://www.spriters-resource.com/amstrad_cpc/cabal/asset/246316/)
- [Bosses](https://www.spriters-resource.com/amstrad_cpc/cabal/asset/246317/)

Как выглядит каждый тип на Dendy и в аркаде — пауза на первой секунде сцены, пока игрок ещё не разнёс фон.

| Кто | Где смотреть |
| --- | --- |
| Зелёный солдат | Любая первая сцена, оба лонгплея |
| Серый гранатомётчик | 1-3, ворота `KEEP OUT` |
| Санитары | Сразу после смерти серого |
| Танки, грузовик, джип | 1-1, 1-2, 1-4 |
| Вертолёт | 1-3 и босс 1 |
| Бомбардировщик | 1-4 и дальше |
| Аквалангист | 2-1 и 2-4 |
| Сайдкар | Аркада, 2-3 |
| Подлодка, тягач, доты, батарея | Боссы 2–5 выше |

Лонгплеи, с которых удобно снимать позы:

- Dendy, список прохождений: [GameFAQs, Cabal NES videos](https://gamefaqs.gamespot.com/nes/587166-cabal/videos). Бери `Cabal (NES) Playthrough - NintendoComplete` или `Cabal - NES Longplay`.
- Аркада целиком: [Arcade Longplay 437 Cabal](https://www.youtube.com/watch?v=WPSwJPsPiek).
- Покадровые фото аркады: [The King of Grabs](https://thekingofgrabs.com/2023/06/12/cabal-arcade/).
- Подписанные скриншоты порта NES, уже в бою: [MobyGames](https://www.mobygames.com/game/3733/cabal/screenshots/). В галерее нет отдельных кадров 1-3 и 3-3. 1-3 есть на скриншоте в чате: ворота `KEEP OUT`.
